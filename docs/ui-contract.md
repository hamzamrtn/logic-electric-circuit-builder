# Canvas interface contract

The user's priorities are simplicity, clear organization, discoverable controls and complete editing operations. The schematic is the primary surface. A blank circuit shows a plain grid, with no welcome panel, branding banner, promotional text or empty-state button.

Brief feedback confirms placement, completed connections, pin acquisition and grid snapping. Selection handles fade but stop accepting input immediately on deselection. Fit and Reset animate for 160 ms; direct pointer/wheel gestures cancel motion. Fit reserves space for the actual zoom controls. Nearby exact-center guides and overlap cues never change placement coordinates or block a commit. Reduced Motion removes camera/transform animation and decorative transitions. The detailed timings, lifecycle rules and evidence are in [interaction-feedback.md](interaction-feedback.md).

The toolbar adapts to the measured workspace width. Wide workspaces use one top row; at 900px or less, primary drawing controls use a top dock by default. The same DOM controls retain state while the layout changes. Select, Box and Multi stay together, followed by Wire and Add. File and the paired Undo/Redo stay above the drawing with Inspect and More. Essential controls fit without horizontal scrolling, including a 320px-wide pane. An inline inspector can trigger compact layout in the remaining workspace.

Add opens one searchable parts picker with Electrical, Logic and Connections families, category chips and symbol previews. Text and Custom block are available in its footer. The picker remembers the chosen family/category, closes when a part is chosen, consumes its own pointer sequence, and preserves search/focus during resizing. Compact panes use a bottom sheet; fine-pointer wide panes use an anchored popover. Coarse/touch input focuses the picker rather than automatically raising the keyboard. Search does not move as results change; short views can use the available pane height, with a scrolling content area and reachable search, close and insertion actions.

More contains Select all, Deselect all, grid/snapping options, checks and keyboard-shortcut configuration. The status strip is informational. Rotation stays in the wide toolbar and appears above compact drawing tools during placement. Compact selection rotation is in More and Properties, so selecting an object does not shrink the canvas or move it under the dock. Compact placement puts Cancel beside Rotate. Properties remain closed until requested, and secondary arrangement operations remain grouped under disclosures.

Visible names do not get redundant hover labels. Structural containers, search fields and labelled part cards use referenced accessible names rather than tooltip-triggering aria-label attributes. Icon-only Undo/Redo/Fit controls retain one host tooltip without a native title. Screen-reader names remain available throughout.

Double-clicking a part, wire or junction opens exactly that object's properties, even with Multi enabled. Double-tapping provides the touch equivalent and text annotations retain direct text editing. Pin gestures continue wiring. Blank-canvas right-click leaves the selection, tool and inspector unchanged; an object right-click may inspect that object while Select is active. Property activation does not create a document edit, interrupt wiring or survive a pan/pinch as an unintended double-tap.

More → Keyboard shortcuts configures single letter/number tool keys: V Select, B Box, M Multi, W Wire, R Rotate, F Fit and I Inspect by default. Empty bindings disable an action; conflicts are rejected; defaults can be restored. Keys apply only to the focused drawing, with composition/repeat protection and native input/modifier behavior preserved. Preferences persist through the plugin and notify open views after a successful save. Closing the inspector or shortcut dialog and pointer activation of tool/zoom controls restore drawing focus so tool keys work immediately; keyboard-focused controls retain native behavior.

The inspector presents common fields first. Position & orientation, Pins & connections, Wire connections and selection actions are available through labelled disclosures. Its empty state offers short selection guidance. Objects are grouped by kind, nets show a readable count and expandable terminals, and checks use concise guidance and a quiet success state.

Colors come from Obsidian's background, text, border and interaction CSS variables. The editor has no independent light/dark preference and no forced green palette. The browser development harness supplies representative host variables; this emulation is not shipped. Exports remain self-contained with explicit neutral colors.

Desktop target: 1440x900, full-width canvas until Properties is requested. Phone target: 390x844, compact utility row plus a top tool dock by default; primary controls never require horizontal scrolling. Part previews use a responsive grid and touch controls retain practical hit targets. Popup/inspector sizing uses the actual view container. Palette/property scrolling does not pan the drawing.

A move handle sits at the drawing toolbar's top-left border. Its corner shape is identical in every orientation: a 32px visual grip and 16px icon inside a 44px touch target, with no full-size button card around it. Drag it to an edge to preview and snap to top/right/bottom/left, or tap it for the keyboard-accessible position menu. Center/outside drops and canceled gestures leave the position unchanged. The position is a shared, persisted plugin preference; failed settings writes retain the previous position. Reset restores the responsive default (inline top on wide panes, top on compact panes). Manual top/bottom docking uses a horizontal row; side docking uses a vertical strip, with contained scrolling if the pane is too short. The same controls and circuit session stay mounted.

Canvas space and the parts picker adapt to the chosen edge. Zoom controls sit above the bottom dock, at the top-right for top/left docking and at the top-left for right docking. Fit accounts for their actual corner and any floating host navigation obscuring the canvas. Visible floating phone navigation reserves clearance around bottom/side controls and modal pickers through host CSS variables; the entire view is not padded. Hidden navigation, tablets and ordinary docked navigation do not add that reservation; negative keyboard spacing clamps to zero. Host navigation and circuit geometry are unchanged.

Recovery settings keep the path input, folder suggestions and a native Apply button in one setting row. Typing changes a draft only. Apply is disabled until the path changes and validates; migration disables the controls, and an error stays inline with the draft available for retry. The generated README starts with the plugin's name and explains its purpose before location instructions; internal ownership markers must not appear in the note.

Wire Finish ends at the final explicitly placed canvas point. It creates one atomic edit, consumes the control event and returns to Select. A pointer-up without a matching canvas pointer-down performs no drawing action. Selection rectangles have 8% fill opacity. Zoom buttons step through 25-point percentage stops; wheel/pinch remain continuous and anchored.

Canvas touch navigation owns its gestures: horizontal and downward swipes must not activate Obsidian's drawers or pull-down actions. Pinch zoom uses both fingers' latest positions and follows their midpoint. Lifting either finger continues a pan with the remaining finger; navigation never places parts or commits an interrupted object drag. Toolbar and inspector scrolling retain their own touch behavior.

Selection uses screen-sized proximity targets even when a wire's visible stroke becomes thin at low zoom. Ambiguous nearby objects use an explicit chooser. Locked inspector fields remain visible but disabled; the selection actions identify whether to unlock the selection or a protecting group. Commands recheck the current lock when committing, including dialogs opened before another view changes the lock.

Selecting a group from the object list highlights and drags its members without turning the selection into separate objects. Delete on only the group container retains its contents; Cut transfers the group's editable contents as one undoable operation. Split wires and inserted parts retain their owning groups. Connection choosers preserve Multi/Shift selection, contain keyboard focus and close on Escape without canceling the wire draft. Failed form submissions retain focus for keyboard correction.

Text and annotations show a bounding frame, four resize handles and a round rotation handle when selected. They can be moved by dragging. Text resizing preserves proportions by default; Shift permits free scaling. Numeric transform controls provide a non-drag alternative. Double-clicking text opens its editor. A completed gesture is one undo step and cancellation leaves the committed document unchanged.

Loading is performed by the host before the standalone editor receives a validated document. Invalid/future imports preserve the current drawing and expose a specific error. Save/conflict failures retain recovery actions. No account, network or runtime authorization prompt is part of the editor. Clipboard remains optional. Keyboard focus, text-field shortcut isolation, reduced motion, light/dark colors and touch layout are reviewed separately from actual device qualification.

0.1.2 consolidates File, editing tools, parts, selection and Properties into one toolbar row. The duplicate document header is removed; title editing and exports are in File, save state stays in the existing status strip. Enter uses Finish only for an active wire draft while the canvas owns focus. Existing wires snap along their segment when Snap is enabled. Pin/junction targets take priority. Connection hints and branch lists use readable names/numbers rather than internal identifiers.
