# Logic-Electric Circuit Builder 0.1.4

Create electrical and logic schematics inside Obsidian, offline. Requires Obsidian 1.14.0 or later.

- Draw with 72 built-in symbols, explicit pin connections, branches, and custom blocks.
- Move, rotate, and mirror connected parts; undo edits and inspect structural connection checks.
- Embed circuit previews in notes and export portable SVG and PNG images.
- Save drawings as `.lecircuit` files with autosave, conflict handling, and recovery copies.
- Version 0.1.4 refines the grid and routes orthogonal wires around component bodies while retaining selected waypoints. Unconnected wire crossings remain separate; junction dots mark explicit connections.

This is a schematic editor; it does not simulate circuits. Real-device mobile qualification and the full Chromium/WebKit suite remain pending; see `docs/validation.md` and `docs/evidence/release-0.1.4.md` in the source repository.

## Release attachments

Attach `main.js`, `manifest.json`, and `styles.css` individually to GitHub release tag `0.1.4`. The optional `logic-electric-circuit-builder-0.1.4.zip` contains the same three files in the plugin folder for manual installation.

For manual installation, copy the three files into `<vault>/<configDir>/plugins/logic-electric-circuit-builder/`, reload Obsidian, and enable the plugin in Community plugins. The usual configuration directory is `.obsidian`.
