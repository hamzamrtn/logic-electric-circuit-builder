**Choose where recovery backups live, with less clutter in your daily workspace.**

- Choose a **Recovery folder** in the plugin’s Obsidian settings, then select **Move backups**. Existing plugin backups move there without overwriting destination files or moving unrelated content.
- Follow folder and parent-folder renames, and reuse backups you moved manually before updating the setting. Failed migrations preserve your snapshots.
- Optionally exclude the recovery folder from Search and Graph and deprioritize it in Quick Switcher. The plugin tracks only its own exclusion; existing user rules are preserved.
- Add a brief `00_README.md` explaining where the backups came from, how they help and how to move them. Existing recovery folders receive it when the updated plugin loads.

Original circuits stay in place. Backup retention is unchanged. Automatic exclusion depends on optional host support; backup saving remains available if that integration is unavailable.

Requires Obsidian 1.14.0 or later.
