# Logic-Electric Circuit Builder 0.1.5

Addresses automated community review findings in 0.1.4. Requires Obsidian 1.14.0 or later.

- Scoped CSS replaces static style assignments and `!important` overrides.
- Searchable declarative settings preserve grid, snapping and export-folder preferences.
- Dialog submission and preview loading handle asynchronous work through synchronous event/lifecycle callbacks.
- Explicit preview paths resolve directly; legacy basename lookup and the circuit picker still enumerate vault file paths, as disclosed in the README.
- React 18.3.1 supplies the editor's hooks and portals without React 19's external-resource script loader. Dependency files are unmodified.
- GitHub Actions checks the source, builds from the release tag, attests the three install assets, and attaches those exact bytes to the release.

This release still requires the Obsidian Community branch/release scan. A successful build or local lint run does not guarantee directory acceptance. Real Obsidian/device qualification remains recorded separately in `docs/validation.md`.
