**A cleaner circuit workspace on every screen.**

- A responsive toolbar puts drawing tools in a bottom dock in compact panes and keeps one tidy top row when there is room.
- Undo/Redo stay visible. Add brings Electrical, Logic, Connections, Text and Custom blocks into one searchable picker.
- A calmer inspector groups related actions, while duplicate and redundant tooltips are removed.
- Double-click or double-tap to inspect an object reliably, including with Multi enabled. Right-clicking empty canvas keeps the workspace unchanged.
- Customize canvas tool keys under More → Keyboard shortcuts. Typing in notes, fields and dialogs keeps its native behavior.
- Softer corners, balanced spacing and subtle depth work with Obsidian's light and dark themes. The screenshot gallery is refreshed.
- Improve split-pane, short-screen and keyboard-height layouts, preserve focus when controls close, and fit saved circuits correctly on opening.

Requires Obsidian 1.14.0 or later.
