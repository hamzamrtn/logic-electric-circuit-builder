# Security

The plugin has no accounts, telemetry, runtime network calls, native filesystem access or executable component plugins. Imports are bounded and validated; custom drawings accept a small declarative primitive vocabulary. Text is escaped in exports, and SVG has no scripts, external assets or foreignObject content.

Do not post private vault contents or secrets in public issues. A report should include the plugin/Obsidian version, minimal sanitized reproduction and the observed effect. Security fixes must preserve malformed originals and must not auto-rewrite unsupported files.
